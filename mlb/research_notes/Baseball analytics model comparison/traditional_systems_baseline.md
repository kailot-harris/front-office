# Traditional MLB Projection Systems: Methodology and ML Comparison Baseline

## What is the core methodology of each system (Marcel, PECOTA, ZiPS, Steamer, THE BAT/THE BAT X), who created them, and when?

### Takeaway
All five systems share a common skeleton — multi-year weighted-average performance data, regression toward a league-average mean, and an age/aging-curve adjustment — but they differ sharply in sophistication: Marcel is a deliberately minimal, transparent "three-years-weighted-plus-regression-plus-age" formula; Steamer and ZiPS add player-specific/position-specific regression and growth/decline curves plus (for ZiPS) comparable-player matching and Monte Carlo simulation; PECOTA is explicitly a nearest-neighbor/comparable-player (k-NN-style) system distinguishing it from the regression-weighted-average family, and was rebuilt in 2020 into a wholly new, BP-proprietary engine; THE BAT and THE BAT X are built on sabermetric regression methodology but THE BAT X is the one system in this set that explicitly ingests Statcast data (and, per its creator, machine learning for some sub-components like ownership projections and the "stuff model").

### Cited Findings
- **Marcel ("Marcel the Monkey Forecasting System")**: created by Tom Tango (Tango Tiger), introduced 2004. Uses three years of MLB data with more recent years weighted more heavily, regresses every player toward the league mean, and applies a simple age-based adjustment factor. Each player also gets a "reliability" factor (higher with more playing-time data; young/untested players get low reliability and projections near league average). Tango describes it as "the most basic forecasting system you can have, that uses as little intelligence as possible," explicitly designed as **the minimum-competence baseline that other systems should beat** — not intended to be the most accurate system. — [MLB Glossary: Marcel](https://www.mlb.com/glossary/projection-systems/marcel-the-monkey-forecasting-system); [Marcel 2012 (Tango)](https://tangotiger.net/marcel/); [FanGraphs: Tangotiger's Projection Tests](https://blogs.fangraphs.com/tangotigers-projection-tests/); [FanGraphs Library: The Projection Rundown](https://library.fangraphs.com/the-projection-rundown-the-basics-on-marcels-zips-cairo-oliver-and-the-rest/)
- Marcel "does not know that the minor leagues exist," is "not persuaded by player comparison," and "makes no guesses at the effects of injuries" — i.e., no comparable-player matching, no scouting input, no Statcast/ML component. — [FanGraphs: Tangotiger's Projection Tests](https://blogs.fangraphs.com/tangotigers-projection-tests/)
- **PECOTA** ("Player Empirical Comparison and Optimization Test Algorithm") was developed by **Nate Silver in 2002–2003**, first published publicly in *Baseball Prospectus 2003*. Unlike the regression/weighted-average family, PECOTA's defining methodological choice is matching each player to his **100 closest statistical comparables** (originally the top ~20 nearest comparables were used for the projection itself) drawn from a database of historical MLB and minor-league player-seasons, using a similarity score computed across performance/attribute vectors (contact rate, power, speed, plate discipline for hitters; strikeout rate, groundball tendency, walk rate for pitchers), with a multi-dimensional Euclidean-distance-style metric — functionally a k-nearest-neighbor approach rather than a parametric regression. — [Wikipedia: PECOTA](https://en.wikipedia.org/wiki/PECOTA); [Wikipedia: Similarity score](https://en.wikipedia.org/wiki/Similarity_score); [BP: 10-Year Projections, UPSIDE, Percentiles, and Comparables](https://www.baseballprospectus.com/news/article/23016/baseball-prospectus-news-10-year-projections-upside-percentiles-and-comparables/)
- PECOTA underwent a **complete rebuild in 2020** ("PECOTA Week 2020") described by Baseball Prospectus as "a completely new engine, built from the ground up," no longer containing any of Nate Silver's original code, and now fully integrated with BP's proprietary "Deserved" metrics (Deserved Runs Against [DRA] for pitchers, Deserved Runs Created [DRC+] for hitters). — [SABR: Judge, "Introducing PECOTA 2020"](https://sabr.org/latest/judge-introducing-pecota-2020/); [BP: Cracking Crystal — The 2020 PECOTA Standings Projections](https://www.baseballprospectus.com/news/article/57019/pecota-2020-mlb-standings-projections/)
- **ZiPS** ("sZymborski Projection System") was developed by **Dan Szymborski**, a senior writer at FanGraphs. It uses growth/decline (aging) curves by player type applied to weighted past performance, draws on the prior **four seasons** of data (weighted roughly 8/5/4/3 for recent-to-oldest) for players aged 24–38, and only the last three seasons for players under 24 or over 38. Similar to PECOTA, it also uses comparable historical players (plus velocity/pitch data for pitchers) to refine its baseline, stores first-through-99th-percentile projections per player, and for team-level standings projections runs Monte Carlo simulation (a million simulated team seasons). — [Beyond the Box Score: projection systems guide (2016)](https://www.beyondtheboxscore.com/2016/2/22/11079186/projections-marcel-pecota-zips-steamer-explained-guide-math-is-fun); search summary citing FanGraphs/ESPN methodology descriptions of ZiPS — [Wikipedia: Dan Szymborski](https://en.wikipedia.org/wiki/Dan_Szymborski)
- **Steamer** was created by **Jared Cross** (a high-school science teacher) with former students **Dash Davidson and Peter Rosenbloom**, originally as a high-school project. Its core method is a weighted average of past performance regressed toward league average, but — unlike Marcel's fixed weights — the weighting and regression amount for each statistic are themselves derived from regression analysis of historical player data (i.e., "the weights and the amount of regression are based on the player in question rather than a fixed set of numbers"). Adjustments are made for park effects, league effects, aging, and starter/reliever role; a reliability value (0 to 1, higher with more career playing time) determines how much a player's rate stats are pulled toward league mean. Steamer has been described as methodologically positioned "somewhere in the middle" between the simplicity of Marcel and the complexity of ZiPS. — [Beyond the Box Score (2016)](https://www.beyondtheboxscore.com/2016/2/22/11079186/projections-marcel-pecota-zips-steamer-explained-guide-math-is-fun); [FanGraphs: Alek Manoah's Steamer Projection Is a Feature, Not a Bug](https://blogs.fangraphs.com/alek-manoahs-steamer-projection-is-a-feature-not-a-bug/); [Steamer Projections — About](http://www.steamerprojections.com/index.php/privacy-policy/2-about)
- **THE BAT / THE BAT X** were developed by **Derek Carty**, who describes 10+ years and 10,000+ hours of development, building on sabermetric methodology from the broader analytics community. **THE BAT X**, introduced around 2020, is explicitly described as "THE BAT... plus Statcast" — a "majorly upgraded version of THE BAT using Statcast data." It incorporates a proprietary "stuff model" called **THE BATcast**, which uses Statcast pitch-level data (velocity, movement, spin, etc.) to project pitchers, and includes machine-learning-built ownership projections for DFS. This makes THE BAT X the only system of the five in this review that is documented as directly incorporating both Statcast-derived inputs and an internal machine-learning component (at least for sub-outputs like ownership projections and the "stuff" model), rather than relying solely on traditional box-score-level regression. — [RotoGrinders: THE BAT X Projections! THE BAT... plus Statcast!](https://rotogrinders.com/pages/the-bat-x-projections-the-bat-plus-statcast-3361569); [Derek Carty on X, announcing THE BAT X](https://twitter.com/DerekCarty/status/1271071869127593984); [RotoGrinders: THE BAT X Projection System by Derek Carty](https://rotogrinders.com/the-bat)

### Inferences
- Methodologically these five systems fall on a spectrum: Marcel (pure weighted-average + regression + age, no comps) → Steamer (player-specific weighted-average + regression, backtested) → ZiPS (aging curves + comparable players + Monte Carlo) → PECOTA (pure nearest-neighbor comparable-player matching, now a proprietary "Deserved"-metric-integrated engine) → THE BAT X (traditional regression core, but augmented with Statcast inputs and discrete ML components). None of the publicly documented methodologies for Marcel, Steamer, or classic ZiPS claims to use modern ML techniques (random forest, gradient boosting, neural nets) as the primary model; PECOTA's nearest-neighbor comparable-matching is a form of classical (pre-deep-learning) statistical learning, and its 2020 rebuild's internals are largely proprietary/undisclosed beyond "completely new engine."
- Because THE BAT X is the only system with a confirmed internal ML component, any "ML vs. traditional system" accuracy comparison that includes THE BAT X should be read carefully — it is not a clean ML-vs-non-ML comparison, since THE BAT X itself already blends traditional regression with ML/Statcast elements.

### Gaps
- No public, detailed technical writeup was found describing the exact current (post-2020) PECOTA algorithm's internals (e.g., whether DRC+/DRA inputs are generated via regression, mixed models, or ML); Baseball Prospectus has not published full code or a peer-reviewed methodology paper.
- No primary Derek Carty methodology document (e.g., a dedicated whitepaper) was retrieved describing exactly which parts of THE BAT X use machine learning versus traditional regression beyond the "stuff model" (THE BATcast) and DFS ownership projections; this comes from Carty's social-media announcements and RotoGrinders marketing copy rather than a technical paper, so should be treated as a secondary/promotional source, not a peer-reviewed or fully transparent methodology disclosure.
- Could not retrieve ZiPS's primary methodology page directly (FanGraphs author archive pages did not yield a dedicated technical writeup in this session); ZiPS details above come from secondary summaries (Beyond the Box Score 2016, Wikipedia).

## What accuracy benchmarks are typically reported for these systems (FanGraphs/THT "best projection system" reviews, Tango's work, FantasyPros studies)?

### Takeaway
The two most citable recurring empirical benchmarks are (1) Dan Meyer's 2014 Hardball Times study comparing wOBA mean absolute error across Marcel/ZiPS/Oliver/PECOTA/Steamer, which found all systems clustered tightly (MAE range ~.0269–.0289) with ZiPS slightly best overall; and (2) FantasyPros' annual "Most Accurate Fantasy Baseball Projections" study (running since ~2019), which uses a z-score-based error-ranking methodology (not raw RMSE/correlation) and has found THE BAT X to be the most accurate *original* (non-consensus) system for multiple consecutive years, including reportedly becoming the single most accurate system overall in 2024.

### Cited Findings
- **THT 2014 study** (Dan Meyer, "Evaluating the 2014 Projection Systems," published Dec. 18, 2014): compared Marcel, ZiPS, Oliver, PECOTA, and Steamer on weighted mean absolute error (MAE) for projecting 2014 wOBA, normalizing all systems to a common league-average baseline (.315 wOBA) and filling missing projections with a value 20 points below league mean. Results (MAE): **ZiPS .0274** (best overall), **Steamer .0277**, **PECOTA .0279**, **Oliver .0280**, **Marcel .0289** (worst, as expected for the simplest system). Meyer's conclusion: "all these projections do a fine job and the differences between them are subtle." — [THT: Evaluating the 2014 Projection Systems](https://tht.fangraphs.com/evaluating-the-2014-projection-systems/)
- Breaking down by player segment in that same 2014 study: **Steamer** was best for rookies (.0282 MAE), **PECOTA** best for "middling"-experience players (.0273 MAE), **ZiPS** best for veterans (.0269 MAE); for "breakout" players PECOTA and Steamer tied for best, and for "breakdown" (decline) players ZiPS was best — suggesting systems using historical comparable-player matching (ZiPS, PECOTA) did relatively better at capturing unusual performance swings than pure weighted-average systems. — [THT: Evaluating the 2014 Projection Systems](https://tht.fangraphs.com/evaluating-the-2014-projection-systems/)
- **FantasyPros "Most Accurate Fantasy Baseball Projections" annual study**: running continuously since roughly 2019 ("the 6th year of our competition" as of the Feb. 2025-published 2024 results). Methodology: focuses on standard 5x5 roto categories (R, HR, RBI, SB, AVG for hitters; W, SV, K, ERA, WHIP for pitchers) plus playing-time stats (AB, IP); converts each projection's error into a **z-score relative to all competing systems for that player/stat** (not raw RMSE/MAE/correlation), then aggregates; lower (more negative) z-score score = better, zero = average. — [FantasyPros: Most Accurate Fantasy Baseball Projections (2024 Results), published Feb. 4, 2025](https://www.fantasypros.com/2025/02/most-accurate-fantasy-baseball-projections-2024-results/)
- 2024 FantasyPros overall accuracy scores (z-score method, lower/more negative = better): **THE BAT X: -1.874**, Zeile Consensus: -1.867, ATC (consensus) Projections: -1.857, **Steamer: -0.649**, **ZiPS DC: -0.138**. — [FantasyPros 2024 Results (Feb. 2025)](https://www.fantasypros.com/2025/02/most-accurate-fantasy-baseball-projections-2024-results/)
- "For the 6th straight year, THE BAT X has been the most accurate *original* projection system in fantasy, according to studies at FantasyPros" — per Derek Carty's own public statement (2026), and secondary reporting states THE BAT X became, in 2024, "the first original system to ever achieve the most accurate projection system overall" (beating even blended consensus systems that year). Consensus/blended systems (e.g., ATC) had generally ranked #1 overall in prior years through 2023. — [Derek Carty on X](https://x.com/DerekCarty/status/2021659113579852232); secondary summary of FantasyPros multi-year rankings
- Example of raw-error (RMSE) reporting for a non-rate stat: in 2024 plate-appearances (playing-time) predictions, **Steamer had RMSE 169.5**, trailing **ZiPS (RMSE 155.0)** and **THE BAT X (RMSE 156.2)** — one of the only instances found in this research where raw RMSE (rather than a z-score) was explicitly reported for a projection-system comparison. — [search-aggregated summary citing FanGraphs fantasy projection-review content; original article not independently re-verified by direct fetch]
- Steamer ranked 6th and ZiPS "DC" ranked 8th in the FanGraphs/fantasy 2023 projection accuracy rankings cited in secondary summaries of the "2023 Projection Systems Comparison" series. — [FanGraphs Fantasy: 2023 Projection Systems Comparison — A Game Theory Approach](https://fantasy.fangraphs.com/2023-projection-systems-comparison-a-game-theory-approach/) (title/listing found via search; full content not independently fetched in this session)
- Tom Tango has consistently framed Marcel's role not as "most accurate" but as **the floor**: "the minimum level of competence that you should expect from any forecaster," noting that historically, more elaborate systems (ZiPS, Bill James, CAIRO, Oliver, PECOTA) "have only added a small increase in accuracy" over Marcel despite doing substantially more work. — [FanGraphs: Tangotiger's Projection Tests](https://blogs.fangraphs.com/tangotigers-projection-tests/)

### Inferences
- Across more than a decade of informal/semi-formal accuracy studies (2014 THT study through 2024 FantasyPros study), the spread in accuracy between the "best" and "worst" traditional system is consistently narrow — on the order of a few percent in MAE/RMSE terms, or a few tenths of a z-score point — reinforcing Tango's claim that elaboration yields diminishing returns over the Marcel baseline.
- The accuracy-ranking methodology has shifted over time from raw statistical error metrics (THT 2014's MAE-based study) toward relative z-score-based "fantasy-relevant" rankings (FantasyPros since ~2019), which makes it harder to directly compare pre-2019 and post-2019 published accuracy figures on a common scale (MAE/RMSE vs. z-score).
- THE BAT X's recent dominance in the FantasyPros rankings is notable precisely because it is the one system with documented ML/Statcast components, which is suggestive (though not proof, since it's a bundled system) that Statcast-informed, partially ML-driven modeling does measurably outperform pure traditional-regression systems in practice, at least by the z-score fantasy-accuracy metric used by FantasyPros.

### Gaps
- Could not independently fetch and verify the full content of the FanGraphs "20XX Projection Systems Comparison — A Game Theory Approach" series (2020–2024) or the full 2024 FanGraphs "Projection Review: Batter Playing Time" article; figures cited above for those come from aggregated search-result summaries rather than direct primary-source verification, and should be treated with appropriate caution.
- Did not find a continuously-published, single, authoritative year-by-year RMSE/MAE/correlation leaderboard spanning all five systems from 2014–2026; the evidentiary record is a patchwork of one 2014 THT study (raw MAE) and the FantasyPros z-score series (2019–2025), with no single consistent metric across all years.
- No peer-reviewed (academic) source was found for any of these accuracy benchmarks — all are sabermetrics blog/website (FanGraphs/THT, Beyond the Box Score) or trade-press (FantasyPros) sources, not academic literature.

## Has any academic paper, Kaggle competition, SABR/Sloan paper, or blog post directly pitted an ML model (random forest, gradient boosting, neural net) against Marcel, PECOTA, ZiPS, Steamer, or THE BAT, with reported comparative accuracy (RMSE/MAE/correlation)?

### Takeaway
The clearest documented academic (peer-reviewed) head-to-head is Sun, Lin & Tsai's 2022/2023 LSTM paper, which benchmarked an LSTM neural network against ZiPS (and references PECOTA/Marcel as commonly-used comparison systems) for predicting MLB home run totals, reporting that LSTM beat ZiPS and other baselines on both MAE and RMSE in the 2018–2019 test seasons, especially for players with under 30 home runs; no SABR/Sloan-presented paper benchmarking ML against these specific MLB systems was found (the one Sloan paper surfaced, "MAYFIELD," is an NFL-player-development model, not MLB, and is therefore out of scope).

### Cited Findings
- **Sun, H.-C., Lin, T.-Y., & Tsai, Y.-L., "Performance prediction in major league baseball by long short-term memory networks,"** *International Journal of Data Science and Analytics*, vol. 15, pp. 93–104, **2023** (preprint posted to arXiv as 2206.09654 in **2022**). This is a peer-reviewed journal article (published in a Springer journal), making it the strongest-sourced academic comparison found in this research. — [Springer: Int J Data Sci Anal 15, 93–104 (2023)](https://link.springer.com/article/10.1007/s41060-022-00313-4); [arXiv preprint 2206.09654 (2022)](https://arxiv.org/pdf/2206.09654)
- The paper's target variable is MLB player **home run totals**; it compares LSTM-network predictions against established projection systems (specifically **ZiPS** is named as a comparison baseline) and against traditional machine learning methods, using **MAE and RMSE** as the accuracy metrics. — [arXiv 2206.09654](https://arxiv.org/pdf/2206.09654); search-aggregated abstract summary
- Reported result: in the **2019** season predictions, **four of five LSTM model variants outperformed all other methods (including ZiPS) on both MAE and RMSE**; the LSTM models "outperformed other methods, demonstrating a lower mean absolute error (MAE) and a lower root mean square error (RMSE) in the 2018 and 2019 predictions," with the improvement over ZiPS specifically noted as more pronounced "for players hitting fewer than 30 home runs." — [search-aggregated summary of arXiv 2206.09654 / Springer version; exact numeric MAE/RMSE values for LSTM vs. ZiPS were not retrievable — the PDF could not be parsed as text in this session, see Gaps]
- The paper's background/related-work section references **PECOTA and Marcel** as "popular existing methods for performance prediction in baseball" that it situates itself against, though the detailed head-to-head numeric comparison reported was specifically against ZiPS and other ML baselines rather than against Marcel or PECOTA directly. — [search-aggregated summary of arXiv 2206.09654]
- A Sloan Sports Analytics Conference paper titled **"MAYFIELD: Machine Learning Algorithm for Yearly Forecasting Indicators and Estimation of Long-Run Player Development"** (Williams, Clarke, Brugler; Ohio State University / General Motors; presented 2021) uses a k-nearest-neighbor regression model with locality-sensitive hashing to forecast **NFL** (not MLB) player statistics; it is explicitly an American football model and is therefore **out of scope** for this MLB-focused review despite surfacing prominently in searches for "Sloan machine learning baseball projections." — [Sloan Sports Conference: MAYFIELD paper page](https://www.sloansportsconference.com/research-papers/mayfield-machine-learning-algorithm-for-yearly-forecasting-indicators-and-estimation-of-long-run-player-development); [OSU Sports & Society summary](https://sportsandsociety.osu.edu/student-research-winner-williams-clarke-and-brugler-mayfield-machine-learning-algorithm-yearly)
- A Stanford CS229 course project, **"Predicting the Offensive Performance of MLB Position Players"** surfaced in search results as a candidate ML-vs-traditional-system comparison, but its content (methodology, baselines used, and whether it benchmarks against Marcel/PECOTA/ZiPS/Steamer/THE BAT with specific RMSE/MAE numbers) was **not verified** in this session — it is a student course project, not peer-reviewed, and would need direct review before citing specific figures. — [Stanford CS229 project PDF (title found via search, not fetched)](https://cs229.stanford.edu/proj2019aut/data/assignment_308875_raw/26382632.pdf)
- No results were found indicating a **Kaggle competition** specifically benchmarking ML models against Marcel, PECOTA, ZiPS, Steamer, or THE BAT for MLB player projections; none of the searches in this research surfaced such a competition.

### Inferences
- The strongest available academic evidence (Sun, Lin & Tsai 2022/2023) suggests LSTM-based deep learning can outperform at least one traditional system (ZiPS) on a narrow, single-stat target (home runs) by both MAE and RMSE, but this is a single-stat, single-paper result — it does not generalize to full-stat-line hitter/pitcher projections, nor does it include PECOTA, Steamer, Marcel, or THE BAT as direct numeric comparators in the reported head-to-head results.
- The scarcity of rigorous academic (peer-reviewed) ML-vs-traditional-system comparisons for MLB projections — as opposed to abundant sabermetrics-blog-level accuracy reviews (FanGraphs/THT/FantasyPros) — indicates this remains a thin area of the formal literature relative to the volume of industry/hobbyist projection work.

### Gaps
- Could not retrieve the exact numeric LSTM-vs-ZiPS MAE/RMSE values from the Sun, Lin & Tsai paper; the PDF fetched in this session returned only binary/compressed-stream content and could not be parsed as readable text, and the Springer-hosted full-text version was not independently fetched. The qualitative claim ("LSTM beat ZiPS and other methods on MAE/RMSE in 2018–2019") is corroborated by multiple independent search-result summaries, but precise numbers are a gap.
- No source was found reporting a direct numeric ML-vs-PECOTA, ML-vs-Steamer, or ML-vs-THE BAT accuracy comparison (RMSE/MAE/correlation) in either academic or blog literature, despite targeted searching; this appears to be a genuine gap in the publicly available literature rather than a search failure, since multiple query variations (random forest/gradient boosting/neural network vs. each named system) returned no on-point results beyond the ZiPS-vs-LSTM paper above.
- No SABR convention paper (SABR Analytics Conference) specifically benchmarking ML against these five systems was located; only the (MLB-relevant) SABR article on PECOTA's 2020 methodology overhaul was found, which does not involve an ML-vs-traditional comparison.
- Did not find a published source clarifying whether the Sun/Lin/Tsai paper's "traditional machine learning methods" baseline category included gradient boosting or random forest specifically (vs. e.g. simple regression) — the exact baseline ML model types benchmarked are unconfirmed.

## What is Derek Carty's published methodology for THE BAT / THE BAT X, specifically any ML component?

### Takeaway
Derek Carty has not published a detailed technical/academic methodology paper for THE BAT or THE BAT X; available documentation is limited to his own social-media announcements and marketing copy (via RotoGrinders, where THE BAT X is sold), which describe THE BAT X as "THE BAT X = THE BAT + Statcast," built on a proprietary pitcher "stuff model" (THE BATcast) that uses Statcast pitch-tracking data, plus separately-described machine-learning-built DFS ownership projections — but the underlying algorithms, feature sets, and model architecture are not disclosed in enough detail to characterize precisely which components use classical regression versus true ML techniques (random forest, gradient boosting, neural nets, etc.).

### Cited Findings
- Carty's own description (2020, via X/Twitter): "THE BAT X is a **majorly upgraded** version of THE BAT using Statcast data!" — introducing it alongside "THE BATcast Tools." — [Derek Carty on X, 2020 thread](https://twitter.com/DerekCarty/status/1271071869127593984)
