First, run the development server:


## Build output (`web/out/`)

`next.config.mjs` sets `output: 'export'`, so the directory `web/out/` is
**generated by `npm run build`** — it is build output, never source.

- `web/out/` is **gitignored** (see `web/.gitignore`), so `git status` will not
  warn you when it is stale. A stale export can serve old season labels and old
  projections even though the JSON in `web/public/data/` and the components are
  already correct.
- Therefore it **must be rebuilt before it is served or deployed**. Use
  `npm run build:verify` to build and then confirm freshness in one command, or
  `npm run check:build-fresh` to check an existing export on its own. The check
  fails when `web/out/` is missing or older than `web/public/data/`.
- **Never hand-edit `web/out/` and never commit it.** Any change belongs in
  `app/`, `components/`, `lib/` or `public/data/`, followed by a rebuild.

The checker accepts `--out <dir>` and `--data <dir>` to compare other
directories:

```bash
npm run check:build-fresh
node scripts/check-build-fresh.mjs --out out --data public/data
```
